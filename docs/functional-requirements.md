# 機能要件

このドキュメントは、Shioriに必要な機能を領域別に整理する。サービス概要ドキュメントで定めた体験設計を実現するために、実装または設計を担うエンジニア・デザイナーが、機能単位で読み解けるように記述する。

各機能には機能ID（領域番号.通し番号、例：2.3）を付与し、関連する機能群はテーブル形式で並列に並べる。要件の本文は完全な文章で記述する。各領域の冒頭には、その領域の位置づけと設計判断の背景を文章で示す。

データモデルに関わる横断的な設計判断は、本ドキュメント全体に影響するため最初に明示する。第一に、スケジュールは地点情報を内部マスタとして持たず、外部地図APIまたはPlace APIの参照をスケジュール自身が直接保持する。第二に、スケジュールの時刻は開始時刻と終了時刻をそれぞれ任意とし、時刻を持たないスケジュールも許容する。

## 認証・ユーザー

ユーザー認証はソーシャルログインで提供する。アカウント登録の手続きを省き、しおり作成までの導線を最短化する。

| ID | 機能 | 内容 |
| --- | --- | --- |
| 1.1 | ログイン | Apple ログインおよび Google ログインでサインインできる。初回ログイン時にユーザーアカウントを自動生成する。 |
| 1.2 | ログアウト | 任意のタイミングでログアウトできる。 |
| 1.3 | ユーザー情報 | 表示名およびアイコン画像を設定・変更できる。 |

## しおり

しおりはこのプロダクトの中心エンティティで、旅行ごとに1件作成される。スケジュールとグループは、しおりに紐づく形で存在する。

| ID | 機能 | 内容 |
| --- | --- | --- |
| 2.1 | 作成 | 新しいしおりを作成できる。タイトル、旅行開始日、旅行終了日、表紙画像、説明文を初期登録できる。 |
| 2.2 | 編集 | 既存しおりのタイトル、開始日、終了日、表紙画像、説明文を編集できる。 |
| 2.3 | 削除 | 作成者がしおりを削除できる。関連するスケジュール情報およびグループも同時に削除される。 |
| 2.4 | 一覧 | 自分が作成したしおりおよび参加中のしおりを一覧表示できる。新着順または更新順で並び替えできる。 |
| 2.5 | 最近見たしおり | 直近で閲覧したしおりを表示し、すぐ再訪できる。 |

## 日程

日程はしおりに紐づく時間単位のスケジュール情報である。スケジュールは1日の中での時間軸を表現する単位であり、時刻、地点情報、メモなどを任意に組み合わせて持つ。地点情報はスケジュール自身が外部API参照として保持し、本サービス内では独立したスポットエンティティを持たない。

| ID | 機能 | 内容 |
| --- | --- | --- |
| 3.1 | 日別タブ | Day 1、Day 2 のような日別タブで切り替えられる。相対日表記と日付表記の両方を扱える。 |
| 3.2 | スケジュール登録 | 各日にスケジュールを追加できる。スケジュールはタイトル、開始時刻、終了時刻、メモ、カテゴリ、作成者を持つ。時刻は任意で、時刻情報を持たないスケジュールも登録できる。 |
| 3.3 | 地点情報 | スケジュールは外部地図APIまたはPlace APIへの参照を任意で持てる。本サービス側で保持するのは外部API識別子のみで、地点名や位置情報、地図リンク、写真などは表示時に外部APIから取得する。 |
| 3.4 | カテゴリ | スケジュールには観光する、食べる、泊まる、買う、移動、その他のいずれかのカテゴリを設定する。 |
| 3.5 | 表示 | 1日のスケジュールを時間帯順に表示する。 |
| 3.6 | 編集・削除 | 既存スケジュールを編集および削除できる。 |
| 3.7 | 地図遷移 | 地点情報を持つスケジュールから、外部地図アプリへ遷移できる。 |

## 写真

写真は独立したエンティティを持たず、スケジュールの地点情報の一部として外部APIから取得・参照される。複数の写真候補から表示するものを選んだり、しおりの表紙として利用したりといった、写真に固有の挙動をここで定義する。

| ID | 機能 | 内容 |
| --- | --- | --- |
| 4.1 | 取得 | 写真はスケジュールの地点情報として外部地図APIまたはPlace APIから取得する。 |
| 4.2 | 表示 | サムネイルと拡大の両方で表示できる。1つの地点について複数枚の写真候補を保持し、切り替えて表示できる。 |
| 4.3 | 表紙利用 | スケジュールの地点情報に紐づく写真を、しおりの表紙画像として利用できる。 |
| 4.4 | 候補編集 | 表示する写真候補を選び直せる。不要な参照を外せる。 |

## 共有・共同編集

しおりは複数ユーザーで共同編集できることを前提とする。共有リンクによる参加と、メンバー間での編集権限の付与を提供する。

| ID | 機能 | 内容 |
| --- | --- | --- |
| 5.1 | 共有リンク発行 | しおりごとに共有リンクを発行できる。発行されたリンクは他ユーザーへの招待に使える。 |
| 5.2 | 共有リンク再発行 | 既存の共有リンクを再発行できる。再発行時は旧リンクが無効化される。 |
| 5.3 | 参加 | 招待されたユーザーがしおりへ参加できる。参加後にメンバーとして表示される。 |
| 5.4 | 編集 | 参加メンバーがしおりの内容を編集できる。変更内容の作成者を識別できる。 |
| 5.5 | メンバー表示 | 参加メンバー一覧を表示する。 |
