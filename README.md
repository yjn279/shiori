# Shiori

旅のしおりを誰かと一緒に作り、思い出として残せる旅行アプリ。修学旅行のしおりが持っていた手触りや温度を、現代のスマートフォン体験として再構築することを目指す。

- [機能要件](./docs/functional-requirements.md) — 機能領域ごとの要件
- [データ要件](./docs/data-requirements.md) — エンティティとデータモデル
